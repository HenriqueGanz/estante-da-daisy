# Especificação — Estante da Daisy

## Visão geral
Aplicativo web para organizar leituras pessoais: catalogar livros com título,
autor, status de leitura, avaliação e citação favorita.

## Requisitos
- Listar livros em cards (título, autor, status, avaliação 1–5, citação).
- Pré-carregar 3 livros de exemplo.
- Formulário para adicionar um novo livro.
- Botão para excluir um livro.

## Stack
- Next.js (App Router) + Tailwind CSS.
- Persistência em memória (useState).

## Paleta
- Fundo creme `#FAF6EE`, texto azul-marinho `#0F172A`.
- Destaques em dourado `#F59E0B` e ciano `#38BDF8`.
